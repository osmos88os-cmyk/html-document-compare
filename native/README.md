# Сверка HTML для Windows

HTMLCompare-Windows7-x64.zip предназначен для Windows 7 SP1 x64. В HTMLCompare-Windows10-11-x64.zip добавлены поиск по журналу, фильтры по решениям и приоритетам, комментарии и история. Оба выпуска используют одно ядро.

Распакуйте архив и запустите HTMLCompare.exe из папки HTMLCompare. Сторонние библиотеки встроены в приложение. Для запуска нужны системные компоненты Windows, указанные в THIRD_PARTY_NOTICES.md.

## Работа с двумя документами

1. Выберите левый и правый HTML, затем нажмите **Сравнить**.
2. Кнопка с биноклем и F11 переключают полноэкранное сравнение. Esc возвращает рабочий вид. F7 и Shift+F7 переходят по различиям.
3. В **Настройках сравнения** выберите видимые категории и режим. Фильтры действуют на список и подсветку. HTML-отчёт содержит все различия.
4. В карточке можно выбрать решение и приоритет. В выпуске для Windows 10/11 можно добавить комментарий. Нажмите **Применить решение**, затем **Сохранить…**.

Для открытия проверки выберите те же HTML, выполните сравнение в том же режиме и нажмите **Открыть проверку…**. Сохранённые решения совместимы между нативными выпусками. JSON из v0.1.0 открывается в [старом выпуске](https://github.com/osmos88os-cmyk/html-document-compare/releases/tag/v0.1.0).

Структурный режим применяет правила для ТЕХН / «Комплекс», ГПУ и КонсультантПлюс. Строгий режим проверяет декодированный текст из HTML, включая пробелы, регистр, знаки и служебную часть выгрузки. Ссылки и отдельные изменения структуры отмечаются дополнительно. Скрипты, внешние ресурсы и текст на изображениях в сверку не входят. Неоднозначное сопоставление блоков и сложная геометрия таблиц требуют проверки.

## Сборка и проверка

Нужны CMake 3.24+ и MSVC 2022 v143 с компонентами C++ x64. CMake скачивает проверяемые по SHA-256 исходники трёх зависимостей на этапе сборки.

~~~powershell
cmake -S . -B build/win7 -G "Visual Studio 17 2022" -T v143 -A x64 -DHTMLCOMPARE_LEGACY=ON
cmake -S . -B build/win10 -G "Visual Studio 17 2022" -T v143 -A x64 -DHTMLCOMPARE_LEGACY=OFF
cmake --build build/win7 --config Release
cmake --build build/win10 --config Release
ctest --test-dir build/win7 -C Release --output-on-failure
ctest --test-dir build/win10 -C Release --output-on-failure
cmake --install build/win7 --config Release --prefix dist/win7/HTMLCompare
cmake --install build/win10 --config Release --prefix dist/win10/HTMLCompare
~~~

GitHub Actions сохраняет кандидатов в **Artifacts**. Для выпуска распакуйте каждый архив на целевых ОС, запустите EXE под обычной учётной записью без сети и проверьте примеры из examples. Убедитесь, что кнопка с биноклем и клавиши работают, длинная вставка не сдвигает следующий пункт и JSON открывается в обеих версиях. Опубликуйте ZIP в Releases после приёмки на Windows 7 SP1, Windows 10 22H2 и Windows 11 x64.

Тест реальных пар запускается локально через **compare_tests --samples ПАПКА_ТЕХН ПАПКА_ГПУ ПАПКА_КП**. Исходные документы остаются на компьютере проверяющего.
